Proyecto principal

ClinicBook

API de citas médicas para clínicas pequeñas. Los pacientes ven los horarios libres de cada médico y reservan uno, los médicos publican las horas que trabajan, y recepción confirma, cancela y agenda para quien llega sin cita.

Java 21 · Spring Boot 4.1.0 · PostgreSQL 16 · Flyway · Docker · Testcontainers · React 18

clinic-book-frontend.vercel.app

El cliente React reservando. La API calcula la grilla desde las horas del médico; las 10:00 ya están ocupadas.

Horarios calculados

Los horarios libres salen del horario del médico y de la duración de la consulta. No hay tabla de horarios que mantener.

Cuatro roles

Paciente, médico, recepcionista y administrador. Los permisos se verifican en cada endpoint, y un médico solo cierra sus propias citas.

Estados de la cita

Pendiente, confirmada, completada o cancelada. El orden se valida en el modelo, no en cada endpoint.

Capas separadas

Las reglas de negocio no dependen de Spring ni de JPA, así que se prueban sin levantar la base de datos.

clinic-book-app.onrender.com/swagger-ui.html

La documentación de la API, generada desde el código. Entras con tu usuario, pegas el token y pruebas cada endpoint desde ahí.
